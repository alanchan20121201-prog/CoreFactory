# 05 · 功能取舍清单（我拍板的结果）

> 判断依据只有两条：**① 是否服务于「轻薄本能跑」；② 是否服务于「永远玩不完」。**
> 不满足的先砍或延后——功能少做不致命，做完做不动才致命。

---

## A. 保留（核心，必须做）

| 功能 | 说明 |
| --- | --- |
| M1 物流形态升级链 | 主骨架。首发只做 **传送带 + 管道**，列车 / 无人机 / 量子隧道按层解锁 |
| M3 蓝图与模块（基础版） | MVP 就要有「框选复制 + 导出字串」，参数化模块放 v1.1 |
| M4 污染双轨 | 首发做简化版：两条路线各一条，不做完整生态模拟 |
| M5 威胁类型库 | 首发只上 **3 种**：空袭群 / 钻地虫 / EMP 潮（其余延后） |
| M7 晶体科技 | **砍到 3 种晶体 × 每种 2 个用途**，不做完整科技树 |
| M10 事件与委托 | 保留。成本低、留存高，是「给没目标的玩家一个推力」的廉价方案 |
| P1 无限研究树 | 保留。成本公式整数化（成本 ×1.35/级） |
| P2 距离梯度与勘探 | 保留。低成本、直接给「去远方」的理由 |
| P4 跨局元进度 | 保留轻量版：成就解锁起始装备，**永不强制重置** |
| P5 / P6 榜单与周挑战 | 保留。v1 = 本地榜 + GitHub 周挑战（见 `04`） |
| QoL 全套 | 复制粘贴 / 幽灵 / 升级规划器 / 俯视设计模式 / 产能计算 / 瓶颈视图 |

---

## B. 删除（不做）

| 功能 | 原因 |
| --- | --- |
| M9 载具与工程机甲（整机驾驶） | 建模 + 物理 + 相机 + 低配适配，成本顶得上半个游戏。**改为「传送站 + 滑翔翼」**解决移动与「后期没事做」 |
| 实时多人联机 | 会让工期翻倍，收益不到 20%（已由 D3 决定） |
| 玩家等级 / 装备 / 属性成长 | 这不是 RPG；玩家变强只能靠工厂 |
| 实时 PvP、需要微操的战斗 | 战斗必须自动化、可预算 |
| 移动端 / VR | 输入与性能双份成本 |
| 开放世界剧情、对话、任务剧本 | 成本黑洞，且与品类核心乐趣冲突 |
| 脚本级 Mod 系统 | 改走数据表 + 蓝图 UGC（见 D4） |
| 体积雾 / SSAO / SDFGI 作为「必开项」 | 降级为高配可选（见 `02` 画质档位表） |

---

## C. 延后（v1 之后）

| 功能 | 延后理由 | 什么时候回来 |
| --- | --- | --- |
| M2 逻辑电路 | 它是「从自动化升级到编程」的关键，但实现与调试成本高 | v1.1（首批 DLC 式更新，作为留存补强） |
| M8 生物驯化 | 完整生态模拟太贵 | v1 只放 **2 种活体机械**占位，完整版看反馈 |
| P3 新星球（NG+） | 需要先有一个打磨好的星球 | v1.2（第二个星球 = 一个大型更新） |
| M6 天气的完整视觉 | 只保留机械影响 + 简单粒子 | 视表现力反馈再加 |
| 参数化蓝图（带参数占位） | 基础蓝图足够验证玩法 | v1.1 与逻辑电路同批 |
| 中英之外的本地化 | 先做字符串外置 | 上线后按销量决定 |

---

## D. 新增（为了低配与留存而加）

| 功能 | 作用 |
| --- | --- |
| N1 自动降档 | 按帧时间自动调渲染缩放与画质档，低配玩家的救命开关 |
| N2 工厂体检报告 | 瓶颈 / 拥堵 / 空转 / 能耗 + A/B/C 评级；既是 QoL，也是「紧凑度」指标的载体 |
| N3 种子与工厂分享短码 | 一个短码带走种子 / 挑战 / 工厂，传播成本最低的 UGC 形式 |
| N4 设计模式（俯视规划） | 大布局规划 & 蓝图幽灵摆放的专用视角 |
| N5 工厂档案与统计面板 | 回顾帝国用，给「长期游玩」的情绪回报 |
| N6 离线完全可玩 | 不联网也不损失任何功能（排行榜为可选） |

---

## E. 首发（MVP）最终清单

**做**：1 个星球、3 个生物群系、6 种资源、14 种建筑、传送带 + 管道、电力网、基础虫潮（3 种威胁）、存读档、基础蓝图分享字串、工厂体检报告、低/中/高画质三档 + 自动降档、本地榜 + GitHub 周挑战、中英文本外置。

**不做**：列车、无人机、量子隧道、逻辑电路、晶体科技、生物驯化、机甲、多星球、多人、Mod。

**验收线**：集显轻薄本 30 FPS 跑得动；玩家 30 分钟内完成第一次自动化回路自转。
