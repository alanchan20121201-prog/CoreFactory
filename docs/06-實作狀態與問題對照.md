```bash
# 1) Core 層正確性 + 壓測（不需要 Godot）
cd "tools/Bench" && dotnet run -c Release

# 2) 編譯遊戲
cd "../../game" && dotnet build

# 3) 無顯示環境跑遊戲（自動 30 倍速並印出診斷）

# 4) 重新打包 EXE（先匯入資源，再匯出）
cd .. && mkdir -p build
"/c/.../Godot_v4.7.2-stable_mono_win64.exe" --headless --path game --import
```

## 七、v0.3.0 修正紀錄（畫面／圖示／視角）

| 問題 | 根因 | 修法 |
| --- | --- | --- |
| 地形完全看不到、像「空心透明」 | **三角形繞序反了**：程式的索引順序讓右手定則法線朝外，而 Godot 的正面是 CW 繞序（已用 `BoxMesh` 實測：12/12 三角形 agree=0）→ 所有面都是背面 → 從外面看全被剔除 | 反轉 `MeshBuilder` 與 `WorldStreamer` 的所有三角形索引；地形材質再加 `cull_disabled` 雙保險 |
| 建築物頭上沒有任何圖標 | 3D 浮動圖標用自訂 shader 手動組 billboard 矩陣，實際沒有渲染出來 | 改用 **Godot 內建 billboard**（Sprite3D 池 + 圖集快取），零 shader 風險 |
| 一進遊戲看不到角色、要拉到最遠才看到 | 開局鏡頭距離 26、且鏡頭看向 y=2（高於角色） | 距離 11.5、鏡頭對準「腳下地面 + 1.55」（胸口高度）；相機高度改用每幀的地形高度當基準 |
| 第一人稱和第三人稱幾乎一樣 | 第一人稱把相機放在目標點、俯仰角沿用第三人稱（往下 35°），且不隱藏自身模型 | 第一人稱＝**眼睛視角**：高度＝模型實測眼高（1.90）、預設平視、自動隱藏自身；三種視角的 pitch/距離各自獨立 |
| 角色走動時背對行進方向 | 模型實際正面是 **+Z**（用 visor z=+0.17、背包 z=-0.30 實測），程式註解寫成 -Z | `yaw = atan2(dx, dz)`；靜止時轉向鏡頭看出去的方向 |
| 開局一片黑（時鐘 00:xx） | `WeatherSystem` 的 `Time` 從 0 起算＝深夜 | 開局時間設為 `DayLength*0.4`（上午），並重新平衡太陽 0.20+0.78·day、環境光 0.06+0.16·day、地形色 ×0.55（頂點色是線性值，之前整體過曝成灰白） |
| 關閉遊戲時程式崩潰（退出碼 139） | 靜態快取（`IconAtlas._tex`、`FactoryView._iconCache`）在 Godot 釋放資源後仍被 .NET 回收參照 | 退出時清除靜態快取（`_ExitTree` + 統一 `QuitGame()`）；同時把物品實例緩衝 40 萬降到 6 萬。三種退出路徑實測皆為 0 |
| 起伏地形上建造位置對不準 | 滑鼠射線只用 y=0 平面求交 | 迭代 3 次「射線 × 該點地形高度」求交 |
| 內顯（Forward Mobile）噴 SSAO 警告 | 該渲染器不支援 SSAO | 依 `rendering_method` 判斷後才啟用 |

**本輪新增的驗證工具**（之後每次改畫面都該用）：

```bash
cd build
./CoreFactory.exe --resolution 1280x720 -- --shot="C:/tmp/shot_"       # 自動開局 → 5 張截圖 → 退出
./CoreFactory.exe --resolution 1280x720 -- --view=first --shot="C:/tmp/f_"   # 第一人稱
```

`--notut` 可跳過新手教學。截圖模式下每個關鍵幀都會印 `[light]`（時間／日照／太陽能量／環境光），
方便對照畫面亮度。
