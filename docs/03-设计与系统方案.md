# 《星核工厂：无尽深空》设计与系统方案（v2）

> **引擎变更提醒**：本文档撰写于「Electron / 网页」假设之下。运行时现已定为 **Godot 4.7（Mono / C#）**——文中涉及浏览器专属的条目（SharedArrayBuffer、COOP/COEP、WebGL2/WebGPU 兜底、存储配额、Web Worker）请以 `00-决策记录与引擎适配.md` 第三节的「替换表」为准，设计层结论全部保留。
>
> 定位：思路整理稿，用于后续交给 AI 实现。所有系统都按「设计意图 → 实现要点 → 数值起点」三段写，便于直接转成开发任务。
> 第一原则：**无聊 = 玩家已经知道怎么做。** 因此每个系统都在做同一件事——周期性地「换问题」，而不是「加大数字」。

---

## 0. 留存设计哲学（先立规矩）

「无限可玩」由三条腿 + 一个底座支撑：

| 支柱 | 内容 | 解决的问题 |
| --- | --- | --- |
| 横向：新内容 | 新物流形态、新生物群系、新星球（NG+） | 玩完了 |
| 纵向：更深 | 无限研究树、规模与效率纪录、榜单 | 到顶了 |
| 创造：玩家自产 | 蓝图书与模块、逻辑电路编程、展示与录像 | 没目标 |
| 底座：元层 | 跨局进度、周挑战与赛季、榜单、社区 UGC | 重开没意义（但永不强制重置） |

**新功能的准入标准（一票否决制）**：它是否制造了一个玩家必须重新设计方案的新问题？
如果答案只是「+10 攻击力」这类纯数值，一律砍掉。

## 1. 玩法分层（原「三阶段」升级为四层）

| 层 | 时长 | 内容 | 出口条件 |
| --- | --- | --- | --- |
| L1 生存层 | 0~30 min | 手动采集、氧气/体力、简易避难所 | 第一次自动化回路自转 |
| L2 自动化层 | 0.5~10 h | 采矿→传送带→熔炼→组装、电力网、基础防御 | 传送带物流出现明显瓶颈 |
| L3 规模化层 | 10~60 h | 模块化、逻辑电路、列车/无人机、污染治理、虫潮战争 | 常规产能撞到效率墙 |
| L4 超越层 | 60 h+ | 晶体科技、空间压缩、跃迁门、新星球 | 开放式 |

每层的「入场券」＝一次物流形态升级（见 M1）。**层级切换必须伴随旧布局失效**，否则玩家只会原地堆机器。

## 2. 核心新增机制（编号即后续开发任务号）

### M1 物流形态升级链（主骨架）
地面传送带 → 流体管道 → 单轨列车 → 物流无人机 → 量子隧道

- **意图**：每升一级让部分旧布局失效，逼迫重构 = 免费的新内容。
- **实现要点**：所有物流统一为「物流节点」接口（输入槽/输出槽/吞吐/延迟/能耗/优先级），各形态只是参数与摆放规则不同的实现；这样渲染层可统一 LOD 与批处理。
- **数值起点**：
  - L1 传送带 15 件/秒（可叠 3 层）
  - L2 管道 100 单位/秒（仅流体/气体）
  - L3 列车 4000 单位/趟（编组越长越省，需要信号灯与会让）
  - L4 无人机 5 件/秒（直线飞行，需充电桩与航线，穿墙但不穿地形）
  - L5 量子隧道 1000 件/秒（成对建造，能耗随距离平方增长）

### M2 逻辑电路系统（硬核留存的关键）
传感器（储量/温度/流量/敌情）→ 运算器（比较/算术/记忆）→ 执行器（阀门/电机/炮塔/灯）

- **意图**：把游戏从「摆放」升级到「编程」，这是留存时长翻倍的核心系统。
- **实现要点**：每建筑 0~4 个逻辑端口，信号为整型；提供「连线模式」与「示波器」；限制每 tick 求解节点数以保证性能。
- **玩家会自发玩出的东西**：炮弹低于 20% 才开车、按短缺自动切换配方、主电网掉压自动切备用、定时定量出货。

### M3 模块化与参数化蓝图
框选一片建筑保存为「模块」（显式定义输入/输出端口），可像函数一样复用；模块可带参数占位（如「任意配方的熔炼模块」）。

- **意图**：这是 UGC 的地基，也是跨星球复用（P3）的载体。
- **实现要点**：蓝图 = 版本号 + 建筑列表 + 连线 + 端口定义 + 参数占位；压缩后 base64。
- **硬性要求**：旧版本蓝图必须能自动升级或明确报错，绝不静默失效。

### M4 污染双轨（和平派 vs 战争派）
污染/声浪既是威胁来源，也是玩法分支：

- 压制路线：清洁能源、隔音墙、废气回收 → 虫群进化减慢，解锁「共生」结局线。
- 放任路线：高污染换高产率 → 虫群进化加快，但掉落稀有材料。
- **实现要点**：污染按区块累积；`evolution = f(时间, 累计污染, 玩家选择)`，两条路线都要有独立奖励。

### M5 威胁类型库（针对设计而非火力）

| 威胁 | 行为 | 逼迫的设计 |
| --- | --- | --- |
| 空袭群 | 绕过地面防线 | 纵深布置、空中火力、雷达预警 |
| 钻地虫 | 直扑供电与管线 | 电网冗余、分区隔离、地层探测 |
| EMP 潮 | 炮塔瘫痪 20 秒 | 后备系统、机械炮塔、手动开关 |
| 孢子云 | 覆盖地面，减速并腐蚀 | 净化设施、封闭式工厂 |
| 寄生体 | 附着建筑持续掉血 | 巡检机器人、自修复材料 |

- **实现要点**：虫潮用 flow-field 寻路；威胁权重跟随「工厂可探测规模」演化，而非单纯时间，避免挂机被惩罚。

### M6 天气与昼夜（会变化的环境约束）
太阳能夜间归零（逼蓄电/核能）；沙暴加速传送带磨损（逼维护机器人/装甲带）；极光期电网波动（逼稳压器）。

- **实现要点**：天气 = 状态机 + 全局修正系数表，所有建筑读同一份 modifier，便于平衡与调试。

### M7 晶体科技树（L4 的科幻想象力）
- 能量晶：发电与储能；空间晶：瞬移与仓容扩展；时间晶：局部加速/减速。
- 晶体不稳定，会「衰变」，需要稳定器；高阶配方大量消耗晶体。
- **意图**：工业线之外的「超能力」层级，创造新的设计空间与视觉奇观。

### M8 生物驯化（第三条生产路线）
捕获异星生物 → 建巢穴 → 产出「活体机械」：搬运兽、警戒兽、发电兽。

- **意图**：工业/生物/晶体三线并行，形成不同流派，直接提升重复游玩价值。

### M9 载具与工程机甲（后期「玩家有事做」）
建造机甲（建/拆/搬运）、侦察机甲（勘探/战斗）、轨道运输舱。

- **意图**：解决后期玩家只站着看的空虚感，同时降低大幅扩张的移动成本。

### M10 事件与委托
- 随机事件：陨石雨（稀有矿+破坏）、地脉喷发（暴露深层矿脉）、遗迹激活（限时挑战）。
- 委托系统：限时订单（如「30 分钟交付 500 晶体」），给不想自己想目标的玩家一个推力，且可跳过、不破坏沙盒自由。

## 3. 无限与元层（真正的「永无止境」）

### P1 无限研究树
每条科技都有无限层：成本 ×1.35/级，收益递减但永久。配套指标 **SPM（每分钟科研包）** 作为玩家炫耀与竞争的核心数字。

### P2 距离梯度与勘探
资源富度随距离上升，生物群系分带，遗迹密度呈梯度；用探针/卫星逐步解锁地图信息——给「去远方」一个经济动机。

### P3 新星球（NG+）
跃迁门不是结局，而是新星球的入口：重力/大气/温度不同 = 约束不同，逼你重构工厂；可携带 M3 的模块库跨星球复用。

### P4 跨局元进度（不强制重置）
- 成就解锁起始装备/专精（如「开局带 10 块太阳能板」）。
- 赛季徽章、工厂档案馆（历史存档博物馆）。
- **原则**：绝不强制重置，只提供「带着优势重开」的选项。

### P5 榜单与异步竞争
SPM 纪录、最快跃迁时间、最小占地面积、最高性价比工厂（本地 + 云端）。**不依赖实时联机**，对单人游戏最友好。

### P6 周挑战 / 赛季
固定种子 + 固定起点 + 统一目标（如「7 天内做到 1000 SPM」），每周换题。运营成本低、留存高。

## 4. 社群与 UGC

- 蓝图市场：浏览 / 评分 / 标签 / 一键导入，带作者与版本号。
- 工厂快照分享：种子 + 蓝图字串 + 统计数据 = 一个分享码（或文件）。
- 展示模式：自由相机、滤镜、延时录像 → 玩家自发产出内容 = 免费营销。
- 工厂画廊：与榜单联动。

---

## 5. QoL 与留存设施（不是加分项，是必需品）

- 复制粘贴、幽灵蓝图、升级规划器、批量放置、撤销/重做。
- 俯视设计模式（3D 游戏尤其需要一个「画图纸」视角）。
- 内建产率计算器、瓶颈热力图、「为什么卡住」诊断、工厂体检报告。
- 性能 HUD（UPS、实体数、显存占用）。
- 难度自定义：和平模式（无虫潮）、无限资源沙盒、简化电路、加压模式。
- 教程：委托式引导，30 分钟内进第一次自动化。

## 6. 防无聊「变化节奏表」

| 游戏时长 | 玩家此刻的问题 | 你用什么「换问题」 |
| --- | --- | --- |
| 0~30 min | 我会玩吗 | 委托引导 + 第一次回路自转 |
| 0.5~3 h | 产能不够 | 电力网 + 传送带优化 |
| 3~10 h | 物流混乱 | 管道/列车登场，逼重构 |
| 10~25 h | 防不住虫潮 | 威胁类型升级 + 逻辑电路自动补给 |
| 25~50 h | 没有新目标 | 无限研究 + 榜单 + 模块化 |
| 50 h+ | 到顶了 | 晶体科技 → 跃迁门 → 新星球 |
| 通关后 | 结束了？ | 赛季/周挑战/UGC/元进度 |

**排期原则**：大约每 5~10 小时，必须有一次「问题类型改变」；只加数值不加问题 = 玩家流失点。

## 8. MVP 范围建议（第一版做什么）

**做**：1 个生物群系、6 种资源、14 种建筑、传送带 + 管道、电力网、基础虫潮、存读档、蓝图为分享字串、UPS HUD、产率计算器。
**不做（v1 之后）**：列车、无人机、量子隧道、逻辑电路、晶体科技、多星球、多人、Mod。

验收标准：连续游玩 3 小时不出现掉帧与崩溃；玩家能在 30 分钟内产出第一件自动化产品。

## 10. 建议的任务拆分方式（喂给 AI 时用）

按「系统」而不是按「界面」拆，每个任务必须写清四件事：**输入 / 输出 / 接口 / 验收标准**。

示例：
- **Task 01 世界与区块**：接口 `getChunk(cx, cz)`；输出 = 网格高度与资源分布；验收 = 玩家移动 1 km 内存增长 < 50 MB。
- **Task 02 物流节点**：接口 `pushItem(nodeId, item)` / `popItem(nodeId)`；覆盖传送带与管道；验收 = 1 万节点 @60 UPS 不掉 tick。
- **Task 03 存档**：输入 = 世界状态；输出 = 种子 + 区块增量二进制；验收 = 1 GB 工厂存档 < 3 秒、跨版本可迁移。
