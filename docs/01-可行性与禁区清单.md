# 01 · 可行性与禁区清单

> 这份文档只回答一件事：**哪些做不到、哪些绝不能做、哪些是做得到但有代价的妥协。**
> 写在这里的东西默认「不要再讨论」，除非有新的技术证据。违反本清单的设计一律打回。

---

## A. 物理 / 工程上做不到的（必须换实现方式，不要硬上）

| # | 做不到的理想形态 | 必须采用的现实做法 |
| --- | --- | --- |
| A1 | 几万个物品各自做刚体物理、真实碰撞 | 「带段 + 槽位 + 位移进度」的确定性模型，物品不做物理 |
| A2 | 无限大的地图「同时存在」 | 按需生成 + 卸载；离屏区域只是数据，不是实体 |
| A3 | 真正无限的数值成长 | 必撞性能墙；必须设「设计上限」，并把性能做成对玩家透明的项 |
| A4 | 无限世界用 JSON 存档 | 体积爆炸；必须「种子 + 区块增量 + 压缩」的二进制格式 |
| A5 | 大规模实时全局光照 + 数万动态光源 | 烘焙 / 简化 / 限制动态光源数量 |
| A6 | 跨平台 bit 级确定性（为联机/回放） | 极难，因此**暂缓联机**；只保证同版本内可复现 |
| A7 | 几千个单位各自跑 A* 寻路 | flow-field（朝目标的热力场）+ 粗网格定期重算 |
| A8 | 任意脚本 Mod 的安全沙箱 | 不做；改走数据表 + 蓝图 UGC |
| A9 | 真实流体 / 热力学模拟 | 近似参数模型：管道只有吞吐/容量/压力，不做 Navier-Stokes |

---

## B. 做了会毁掉项目的（范围禁区）

| # | 禁忌 | 原因 |
| --- | --- | --- |
| B1 | 开放世界剧情、对话、任务剧本 | 成本黑洞，且与「自动化」品类的核心乐趣冲突 |
| B2 | 首发做多人服务器 | 见 D3；先做单机 + 异步社交 |
| B3 | 移动端 / VR 首发 | 输入与性能双份成本，且目标用户不在那里 |
| B4 | 玩家角色属性成长（等级、装备、攻击力） | 这不是 RPG。玩家变强只能靠工厂，不能靠等级 |
| B5 | 实时 PvP / 需要微操的战斗 | 战斗必须自动化、可预算、可离线推演 |
| B6 | 一次做完 M1~M10 全部机制 | 必须按 MVP 顺序（`03` §8），否则永远做不完 |
| B7 | 为了「更好的画面」牺牲可读性 | 后期玩家是在「读工厂」，不是「看工厂」 |

---

## C. 做得到，但有代价的妥协（要写清边界）

| # | 项目 | 妥协与边界 |
| --- | --- | --- |
| C1 | 工厂规模上限 | 给出性能预算表（例：60 FPS 下 20,000 段传送带 + 100,000 在途物品）；游戏内用「工厂体检报告」透明化，超出即提示 |
| C2 | 图形分级 | 低配机走兼容渲染器，关闭辉光 / 体积雾；不追求极致画质 |
| C3 | 存档上限 | 单存档建议 ≤ 若干 GB；超限给出明确提示，而不是静默卡死 |
| C4 | 首次启动 | 原生导出仍有数百 MB 与数秒启动，这是正常代价，不做无谓优化 |
| C5 | 物理拟真度 | 用「看起来对」的近似模型换取性能，接受不物理真实 |
| C6 | 生物驯化（M8） | 若时间不足，降级为「固定几种活体机械」的简化版，而非完整生态模拟 |

---

## D. 现在（这一阶段）做不到的

| # | 项目 | 说明 |
| --- | --- | --- |
| D1 | 单人半年内交付完整企划 | 不现实。现实预期：单人 18~36 个月到 EA；3 人小队 12~18 个月 |
| D2 | 没有原型就确定全部数值 | 数值必须靠「压测 + 试玩」迭代，先别追求一次定稿 |
| D3 | 同时准备英文与多国本地化 | 先把中英文本分离做好（字符串外置），翻译后置 |

---

## E. 性能预算表（初版草案，随原型修正）

| 项目 | 预算（60 FPS = 16.6 ms/帧） |
| --- | --- |
| 模拟 tick（传送带 + 机械臂 + 电网） | ≤ 5 ms |
| 地形/区块生成与网格化（后台线程） | 每帧 ≤ 1 ms（主线程只做上传） |
| 渲染提交（含 MultiMesh 更新） | ≤ 6 ms |
| 逻辑电路求解 | ≤ 1 ms |
| 虫潮寻路（flow-field 重算分摊） | ≤ 1 ms |
| 余量（UI / 音频 / GC） | ≥ 2 ms |

> 任何新系统加入前，先问：它吃多少毫秒预算？回答不出来就先别做。

---

## F. 一句话总结

**能做的：** 一个规模受控、性能透明、靠「换问题」而非「加数值」维持长期乐趣的单机自动化游戏。
**不能做的：** 真实物理、真无限、实时联机、脚本 Mod、移动端、以及「一次做完」。
