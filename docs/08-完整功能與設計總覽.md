## 2. 設計思路（為什麼這樣做）

### 2.1 第一原則：無聊 = 玩家已經知道怎麼做

所以「讓人一直玩下去」不是靠更多內容，而是靠**週期性換問題**。
新功能的准入標準是一句話：**它是否製造了一個玩家必須重新設計方案的新問題？**
只是加數字、加產量的功能一律不做。

### 2.2 無限可玩的三條腿

1. **橫向新內容** —— 新物流形態、新群系、新礦物、新威脅類型
2. **縱向數值** —— 無限研究樹（永遠還有下一級，成本 1.6 倍遞增）
3. **玩家創造** —— 藍圖、設計模式、工廠檔案、種子短碼；配合異步社群（週挑戰、工廠快照）

### 2.3 玩家體驗的四個階段（心流曲線）

| 階段 | 時間 | 玩家的角色 | 遊戲必須發生的事 |
| --- | --- | --- | --- |
| 手動拓荒 | 0 ~ 30 分 | 自己動手 | 30 分鐘內完成**第一次自動化**（礦機→帶→熔爐→倉庫） |
| 流水線 | 30 分 ~ 20 小時 | 設計師 | 電力、瓶頸、擴張；每個新資源都要重畫一次產線 |
| 自動化帝國 | 20 小時 ~ | 總工程師 | 遠端物流、邏輯電路、國防自動補給 |
| 元層 | 無限 | 挑戰者 | 研究、體檢評級、週挑戰、新星球 |

### 2.4 可讀性 > 畫質（本作最重要的美術原則）

自動化遊戲後期玩家是在「**讀**工廠」而不是「看」工廠。所以：

- 方向用**地面箭頭**（綠＝出貨、藍＝進料）而不是猜
- 傳送帶用**流動條紋**指出輸送方向
- 每種東西有**專屬模型 + 浮動圖標 + 圖鑑說明**
- **低配與高配的模型完全相同**，低配只把材質換成簡化版（去掉反光與發光）——形狀永遠認得出來

### 2.5 效能是設計約束，不是事後優化

模擬與渲染徹底解耦（20 / 30 / 60 UPS 三檔），畫質三檔 + 自動降檔，任何新系統加入前都要先回答「它吃多少毫秒」。

## 3. 玩法閉環

```
礦脈 ──採礦機──▶ 傳送帶 ──▶ 熔煉爐 ──▶ 傳送帶 ──▶ 組裝機 ──▶ 傳送帶 ──▶ 中樞倉庫
                     ▲                                              │
                     │                                         成品入庫存
                 太陽能／火力 ──▶ 蓄電池 ──▶ 電網                   │
                     ▲                                              ▼
                 邏輯電路（感測→比較→執行）                    建造扣庫存
                     ▲
                 蟲潮來襲 ──▶ 砲塔（吃砲彈）
```

- **產物**：鐵板、銅板、齒輪、電路、科研包、砲彈（共 6 種製成品 + 4 種原料）
- **代價**：蓋任何東西都從中樞倉庫扣材料 → 產線停擺就沒得蓋，形成天然的節奏壓力

## 4. 完整功能清單

### 4.1 世界與地形

- **程序化無限地形**（3D 值雜訊 + 種子）：起伏、坡度著色、格線底板質感
- **分塊串流**：32 格一區塊，依相機位置動態生成／卸載，每幀限量建造避免掉幀
- **礦脈**：4 種（鐵／銅／煤／石），稀有度分佈，**有專屬 Blender 模型**（鐵＝銀灰、銅＝橙鏽帶銅綠、煤＝烏黑、石＝灰岩）
- **地表裝飾**：7 種 Blender 模型（大石堆／扁石堆／碎石／水晶簇／小水晶／異星灌木／發光蘑菇），依星球換組合，**純裝飾不擋建造**
- **建造時礦脈會讓位**：在礦脈格或四鄰蓋東西，該格的礦脈自動消失（拆除後長回來）
- **兩顆星球**（見 5.5）

### 4.2 生產與物流

- **13 種建築**：傳送帶、採礦機、熔煉爐、組裝機、中樞倉庫、太陽能板、火力發電機、蓄電池、防禦砲塔、照明燈、感測器、比較器、執行器
- **傳送帶**：帶段 + 槽位模型（每格 8 個物品），自動串接、堵塞回壓、**帶面流動條紋動畫**（速度隨研究與天氣）
- **物品模型**：10 種各有專屬 3D 模型（礦石形狀、板材、齒輪、電路板、試管、砲彈都不同）
- **配方系統**：熔煉爐 2 種配方、組裝機 4 種配方，可用 `Ctrl+滾輪` 在場上切換
- **方向機制**：出貨＝面向方向、進料＝背面方向；**地面箭頭 + 放置預覽旋轉 + 出貨端未接帶立刻警告**

### 4.3 電力

- **太陽能**：白天 60 W，夜間歸零；受天氣影響（晴 100% / 陰 55% / 風暴 22% / 灰燼 18% / 離子 0%）
- **火力發電機**：220 W，燒煤（2 秒一塊）
- **蓄電池**：容量 6000，白天存、晚上放
- **電網結算**：供電不足 → 全廠效率下降（Efficiency 直接乘進生產速度）
- **研究**：發電效率每級 +6%

### 4.4 邏輯電路（玩家要求的「邏輯電腦」）

- **三種節點**：感測器（讀 16 條訊號通道，可讀電池 % / 庫存 / 蟲潮數）→ 比較器（`>` `<` `==` + 閾值）→ 執行器（開關某一類建築）
- **接線方式**：通道編號（0~15），不需要畫線
- **實測有效**：開局示範「電池 < 30% → 自動停熔煉爐」，引擎內實跑驗證（71 W ⇄ 141 W 自動切換）

### 4.5 天氣與晝夜

| 天氣 | 太陽能 | 傳送帶 | 砲塔 |
| --- | --- | --- | --- |
| 晴朗 | 100% | 100% | 正常 |
| 多雲 | 55% | 100% | 正常 |
| 風暴 | 22% | **85%** | 正常 |
| 灰燼風暴 | 18% | **70%** | 正常 |
| 離子風暴 | **0%** | 95% | **週期性癱瘓** |

- 一晝夜 **480 秒**（8 分鐘），開局是明亮上午
- 天空為自寫 `shader_type sky`：漸層 + 會飄的雲 + 夜間星空

### 4.6 威脅與戰鬥

- **蟲潮**：規模 `(3 + 波次×1.6) × 星球威脅 × 設定倍率 + 建築數/30`，第一波 240 秒（灰燼星 150 秒）
- **怪物**：異星甲蟲，**7 部件 Blender 模型 + 六足走路動畫**（腿交替擺動、身體起伏、朝移動方向平滑轉身）
- **砲塔**：射程 10、每 0.55 秒 12 傷害，吃砲彈
- **玩家生命**：兩顆心；怪物靠近會被咬（每 3.5 秒一次），歸零 → 死亡畫面（基地復活但失去一半庫存／讀檔／回主選單）
- **教學期間完全不生成怪物**，教學結束才開始
- **戰鬥音樂**：有蟲潮在場自動淡入緊張曲目，出現瞬間播放號角

### 4.7 研究與元層

- **無限研究樹**（4 條線，成本 `20 × 1.6^等級`，每級 +6%）：
  1. 傳送帶速度
  2. 機械速度
  3. 採礦速度
  4. 發電效率
- **工廠體檢**：每種機器的運轉／堵塞／總數統計，直接指出瓶頸
- **工廠檔案**：這局的統計與評級（含緊湊度概念）

- **藍圖**：`CFBP1` 格式（壓縮 + base64 + 版本號），可複製到剪貼簿分享

### 4.9 介面與體驗

- **主選單**：新遊戲 / 繼續遊戲 / 存檔管理 / 設定 / 離開
- **存檔管理**：每顆星球 3 個欄位 + 自動存檔，可存／讀／刪／**匯出檔案**／**匯入檔案**
- **繼續遊戲回到上次位置**：記錄星球、鏡頭、視角、朝向
- **自動存檔間隔可調**（1~20 分鐘）；離開遊戲自動存檔（可關）
- **面板系統**：
  - 每個面板頂端有一個**小箭嘴**，按下去**整個面板收起來**（▼ ↔ ▶）
  - 開啟任一面板會**自動收起其他面板與教學面板**，關閉後教學自動回來
  - 右側資訊欄與研究面板可折疊、可滾動
- **右側資訊欄**：顯示目前工具與朝向；滑到建築上顯示「熔煉爐：進料 ← 西　出貨 → 東」；滑到礦脈顯示「礦脈：銅礦（把採礦機放在這裡）」
- **圖鑑**：10 種物品與 13 種建築的用途 + 造價
- **說明（怎麼玩）**：目標、第一次玩的五個步驟、方向、核心循環、電力、邏輯、天氣、星球、裝飾說明、介面說明、藍圖、小技巧、完整按鍵表
- **音樂播放器**：4 首程序生成曲目，播放／換曲／調音量／關閉
- **新手教學**：5 階段 11 步，**自動判定完成**、可跳過、可重看任一階段，**高亮該按的按鈕並自動幫你選好工具**
- **地圖**：`M` 開啟俯視圖，建築用圖標畫、蟲潮紅點、玩家位置；左鍵移動鏡頭、右鍵放／刪圖釘（存進存檔）
- **畫質設定**：低 / 中 / 高 / 自訂（渲染縮放、陰影、MSAA、輝光、霧與 SSAO、視距、物品顯示上限、雲層、模型精細度、全螢幕、垂直同步）+ **自動降檔**

### 4.10 音效與音樂（全部執行期合成，零音檔）

- 音效：放置、拆除、錯誤、警報、爆炸、研究完成、蟲潮號角
- 環境音樂：4 首（異星黎明／深空迴響／機械律動／晶體森林），**立體聲 + 4 和弦進行 + 微失諧 + 延遲殘響**，無縫循環
- 戰鬥音樂：138 BPM，大鼓＋小鼓＋八分音符低音＋三全音刺針，**隨蟲潮自動交叉淡入**
- 音量三軌可調（主／音樂／音效）

### 4.11 存檔、資料與更新

- **存檔格式 v4**：種子 + 僅存「被改動的內容」（建築、傳送帶、庫存、研究、圖釘…），二進位、原子寫入、版本遷移分支
- **資料驅動**：所有數值在 `game/data/core.json`（內建）+ `user://data/core.json`（玩家覆蓋，更新不會蓋掉）
- **更新機制**：`VERSION` + `CHANGELOG.md` + `docs/07-更新指南.md` + `.github/workflows/export.yml`（打 tag 自動打包上 Releases）
- **四語言**：簡體中文 / 繁體中文 / English / 日本語，首次啟動**自動偵測系統語言**，遊戲內即時切換（切換透過事件全 UI 重建，不會有殘留）

## 6. 技術架構

### 6.1 分層（最重要的一條工程約定）

```
game/src/Core/   ← 純 C#，完全不引用 Godot（可單測、可移植、可搬去背景執行緒或 GDExtension）
    CoreTypes.cs      資料表 + 列舉 + 建築/怪物結構
    SimWorld.cs       模擬心臟：生產、物流、電力、邏輯、戰鬥、存檔
    Noise.cs          地形 + 礦脈 + 兩顆星球定義
    Weather.cs        天氣與晝夜
    Localization.cs   四語言 + 繁簡轉換
    Persistence.cs    藍圖編碼解碼
    ContentJson.cs    JSON 資料包載入
    Rng / Hash2D      確定性隨機（固定 60 UPS + 種子化）

game/src/Game/   ← Godot 顯示與操作層
    Main.cs           接線、固定步長 tick、設定、存檔流程、命令列參數
    FactoryView.cs    MultiMesh 實例化渲染、天空、箭頭、動畫、幽靈預覽
    WorldStreamer.cs  分塊地形與裝飾串流
    Hud.cs            全程式化 UI（不手寫 .tscn）
    Menu.cs           主選單 / 設定 / 存檔頁
    Tutorial.cs       教學（5 階段，自動判定）
    MapView.cs        地圖與圖釘
    BuildTool.cs      放置 / 拆除 / 旋轉 / 藍圖
    CameraRig.cs      三種視角 + 360° 旋轉 + 縮放限制

    AudioManager.cs   程序化音效與音樂

```

### 6.2 渲染策略

| 做法 | 原因 |
| --- | --- |
| **MultiMesh 實例化** | 2 萬段帶、16 萬物品壓到極少 draw call |
| **每種東西各自一個 MultiMesh** | Godot 的實例顏色只有「網格有頂點色」時有效，一種一個最穩 |
| **傳送帶流動條紋用 Shader** | 0 CPU 成本，2 萬段也在 GPU 端算 |
| **怪物分部件合成** | 7 個 MultiMesh（身體 + 六腿）就能做骨架動畫 |
| **低配＝同幾何 + 簡化材質** | 認得出模型，只差反光（複製 surface 換材質） |
| 陰影 / 輝光 / 霧 / SSAO 依畫質開關 | Forward Mobile（內顯）不支援的要擋掉 |
| 分塊串流 + 每幀限量 | 進新區域不會一次爆掉 |

### 6.3 效能實測（`tools/Bench`，吃同一份 Core 原始碼）

| 規模 | 每 tick | 佔 60 UPS 預算 |
| --- | --- | --- |
| 5,000 段 / 40,000 物品 | 0.154 ms | 0.9% |
| 10,000 段 / 80,000 物品 | 0.300 ms | 1.8% |
| **20,000 段 / 160,000 物品** | **0.696 ~ 0.767 ms** | **4.2 ~ 4.6%** |

設計預算 5 ms → **約 7 倍餘量**。低配 20 UPS 檔位更是綽綽有餘。

| `tools/blender/make_world_models.py` | `ores.glb`（4）、`items.glb`（10）、`monster.glb`（身體+六腿）、`deco.glb`（7 種裝飾） |

### 6.5 品質保證工具鏈（自動化驗證）

```bash
# 1) 模擬層正確性 + 壓測（不需要 Godot）
cd tools/Bench && dotnet run -c Release

# 2) 編譯
cd game && dotnet build

# 3) 無顯示環境回歸（生產鏈、邏輯電路、存檔往返）
godot --headless --path game --quit-after 1200

# 4) 自動截圖驗證（有 GPU 時）
godot --path game --resolution 1280x720 -- --demo --shot="shots/x_"
```

| 參數 | 用途 |
| --- | --- |
| `--shot=<前綴>` | 在第 60/120/220/380/560 幀自動截圖並退出 |
| `--demo` | 蓋一條示範產線（截圖與回歸測試用） |
| `--play` | 無介面直接進遊戲（搭配 `--demo` 做產線回歸） |
| `--monsters` | 直接放行蟲潮並在鏡頭旁生成怪物 |
| `--detail=0/1/2` | 指定模型精細度 |
| `--lang=zh/tw/en/ja` | 指定語言 |
| `--view=first/design` | 指定視角 |
| `--panel=help/codex/music/research` | 開啟指定面板 |
| `--uitest` | 程式化按折疊箭嘴（驗證 UI 互動） |
| `--menu` / `--notut` | 停在主選單 / 跳過教學 |

## 9. 怎麼玩（給第一次接觸的人）

1. **進遊戲**：主選單 → 新遊戲（或繼續遊戲）。畫面中央就是你的角色。
2. **找礦**：按 `M` 開地圖看地形，或 `WASD` 走到附近會發亮的礦石堆（滑鼠移上去右側會顯示是什麼礦）。
3. **第一條產線**：
   1. 底部選「傳送帶」，沿一直線鋪 3~5 格（帶面條紋會告訴你方向，`R` 可轉）
   2. 選「採礦機」放在礦脈上，讓**綠色箭頭**對準那條傳送帶
   3. 傳送帶末端放「熔煉爐」（**藍色箭頭**朝帶子、綠色朝外）
   4. 熔爐出口接一條帶子到「中樞倉庫」
4. **看庫存**：右側物品欄會出現鐵板；蓋東西都從這裡扣。
5. **補電力**：晚上太陽能會失效 → 蓋火力發電機（燒煤）或蓄電池。
6. **教學**：左上角有 11 步引導，會**高亮你該按的按鈕**並自動幫你選好工具；可跳過、可重看。
7. **遇到蟲潮**：會有號角與戰鬥音樂，蓋砲塔（吃砲彈）。
8. **想放鬆**：`F2` 隱藏全部介面；`M` 地圖按右鍵放圖釘記錄位置。
